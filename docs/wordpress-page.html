一个装进用户脚本管理器、在侧边栏里工作的学习通（超星）辅助工具。它把刷课、答题、接口管理收进一块面板： 自动识别当前页面的题目、调用你自己的 AI 生成答案并填入，章节测验按顺序推进。

功能

一块面板做完所有事

  • 一键答题识别当前页面的题目，按题型生成答案并自动填入，支持单选、多选、判断与填空。
  • 刷章节测验按章节顺序自动推进，完成一节测验后跳到下一节，随时可以暂停。
  • API 专刷独立页面批量处理视频与文档，提供正常模式和补时长模式。
  • 多接口管理DeepSeek、OpenAI、Ollama 或任意 OpenAI 兼容接口可以同时存在，分别设置默认与当前使用。
  • 容灾切换当前接口报错时，自动按顺序切换到其他已启用的接口，答题不中断。
  • 选题与正确率右栏列出识别到的题目，可以只答其中一部分；正确率可调，按概率故意答错。

安装

四步开始使用

  1. 安装用户脚本管理器。推荐 脚本猫（ScriptCat），也可以用 Tampermonkey 或 Violentmonkey。
  2. 点上面的「安装脚本」，管理器会弹出安装界面，确认即可。
  3. 打开任意学习通页面，右侧会出现竖排「研习」按钮，点击展开面板。拖动竖条可以调整位置。
  4. 进面板的「设置 → AI 接口」，新增一个配置，填写接口地址与 API Key，选择模型后就能答题。

脚本不自带 AI 服务。它只是一层界面，所有回答都由你自己填入的接口生成，脚本本身不含任何密钥。 支持 DeepSeek、OpenAI、Ollama 以及任何 OpenAI 兼容地址（第三方中转、自建网关都可以）， 地址要写到完整的 /chat/completions。多个接口能同时存在，打开「容灾切换」后某个接口失败会自动换下一个。

常见问题

你可能想知道

面板不出现怎么办？

先在脚本管理器里确认脚本已启用，且当前地址匹配 *://*.chaoxing.com/*。如果脚本更新过仍无反应，用菜单里的「重载插件」手动刷新一次。

答题提示「AI 未配置」？

说明还没有可用的接口。到「设置 → AI 接口」新增一个配置，填写完整的接口地址与 API Key，点「获取模型列表」选中模型。Ollama 这类本地服务不需要 Key，地址填对即可。

可以只答一部分题吗？

可以。题目识别完成后右侧会出现题目分组，取消勾选不想答的题目，再点「一键答题」。

为什么答题正确率可以调低？

低于 100% 时，客观题会按概率故意答错或跳过，用来模拟真实作答节奏。默认 100%。

会不会影响我的账号？

脚本只在你本地浏览器里操作页面与调用 AI 接口，不接管登录状态。但刷课、倍速这类行为本身有被平台判定的风险，请自行评估并遵守课程与平台规则。
