路南云 · 学习通 AI 研习助手

一个装进用户脚本管理器、在侧边栏里工作的学习通（超星）辅助工具。它把刷课、答题、接口管理收进一块面板：自动识别当前页面的题目、调用你自己的 AI 生成答案并填入，章节测验按顺序推进。

脚本猫 / Tampermonkey / Violentmonkey · 单文件无依赖 · Chrome · Edge · Firefox

功能

  • 一键答题：识别当前页面的题目，按题型生成答案并自动填入，支持单选、多选、判断与填空。
  • 刷章节测验：按章节顺序自动推进，完成一节测验后跳到下一节，随时可以暂停。
  • API 专刷：独立页面批量处理视频与文档，提供正常模式和补时长模式。
  • 多接口管理：DeepSeek、OpenAI、Ollama 或任意 OpenAI 兼容接口可以同时存在。
  • 容灾切换：当前接口报错时，自动切换到其他已启用的接口，答题不中断。
  • 选题与正确率：可只答一部分题；正确率可调，按概率故意答错。

安装

  1. 安装用户脚本管理器。推荐脚本猫（ScriptCat），也可以用 Tampermonkey 或 Violentmonkey。
  2. 点上面的「安装脚本」，管理器会弹出安装界面，确认即可。
  3. 打开任意学习通页面，右侧会出现竖排「研习」按钮，点击展开面板。
  4. 进面板的「设置 → AI 接口」，新增一个配置，填写接口地址与 API Key，选择模型后就能答题。
  5. 之后 GitHub main 提高 @version 并推送后，脚本猫 / Tampermonkey 会自动检查更新。

脚本不自带 AI 服务。所有回答都由你自己填入的接口生成，脚本本身不含任何密钥。地址要写到完整的 /chat/completions。多个接口可同时存在，打开「容灾切换」后失败会自动换下一个。

常见问题

面板不出现怎么办？

先在脚本管理器里确认脚本已启用，且当前地址匹配 *://*.chaoxing.com/*。如果更新后仍无反应，用菜单里的「重载插件」手动刷新一次。

答题提示「AI 未配置」？

到「设置 → AI 接口」新增一个配置，填写完整的接口地址与 API Key，点「获取模型列表」选中模型。Ollama 本地服务不需要 Key。

可以只答一部分题吗？

可以。题目识别完成后右侧会出现题目分组，取消勾选不想答的题目，再点「一键答题」。

为什么答题正确率可以调低？

低于 100% 时，客观题会按概率故意答错或跳过，用来模拟真实作答节奏。默认 100%。

会不会影响我的账号？

脚本只在你本地浏览器里操作页面与调用 AI 接口，不接管登录状态。但刷课、倍速这类行为本身有被平台判定的风险，请自行评估并遵守课程与平台规则。
